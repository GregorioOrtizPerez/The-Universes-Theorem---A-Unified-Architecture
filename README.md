# The Universes Theorem: A Unified Architecture

## Overview

This repository accompanies the preprint and monograph detailing the **Universes Theorem** — establishing an exact structural geometry for prime numbers as an alternative to statistical and probabilistic approximations.

## Files in this Repository

* **Monograph:** Full text detailing the tripartite architectural system ($U_1, U_2, U_3$) and structural collision resolution.
* **U1 - Ortiz Perez.py:** Core implementation of the $Fx$ collision engine, demonstrating the deterministic mechanics on the $U_1$ grid.
