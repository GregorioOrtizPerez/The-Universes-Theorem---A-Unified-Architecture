# The Universes Theorem: A Unified Architecture

Repository accompanying the preprint and monograph detailing the Universes Theorem — a closed, deterministic, tripartite architectural system ($U1, U2, U3$) for prime numbers and structural collision elimination on the U1 grid ($6k \pm 1$).

## Files in this Repository
- **Monograph:** Full text detailing the tripartite architectural system.
- `U1 - Ortiz Perez.py`: Core implementation of the Fx collision engine, validating the 0.00% structural error rate.
